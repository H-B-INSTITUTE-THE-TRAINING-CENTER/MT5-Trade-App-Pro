# HB TradePro

HB TradePro is a real-world trading platform built using Python, FastAPI and MetaTrader 5.

## Technology Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
- PostgreSQL
- MetaTrader 5
- React

## Project Goal

Build a real-world trading application capable of:

- Market data retrieval
- Trading account integration
- Portfolio management
- Order management
- Authentication
- Risk management
- Trading analytics
- Dashboard and reporting
